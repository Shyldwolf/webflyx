# WebFlyx 📼🍿

A small **content library** used to practice **Git workflows** and basic **file organization**.

This repo includes sample movie data in **Markdown** and **CSV**, plus folders to practice navigating, reading, and managing files.

---

## 📁 What's inside

- `titles.md` — a list of movie titles  
- `classics.csv` — classic movies in CSV format  
- `guilty_pleasures.md` — “guilty pleasure” movie list  
- `quotes/` — folder with files containing memorable quotes  
- `secure/` — folder reserved for organization/permissions practice  
- `advert.md` — a fun “WebFlyx” promo page  
- `contents.md` — quick map of the collection

---

## ✅ Use cases

- Practice Git: add/commit, branching, merges, resolving conflicts
- Practice file navigation: folders, searching, reading files
- Use this data as input for small scripts (Python, JS, etc.)

---

## 🧰 Tech

- Markdown (`.md`)
- CSV (`.csv`)

---

## 📄 Note

This is a learning repo and is intentionally simple—perfect for practicing clean commits and working with structured text data.
